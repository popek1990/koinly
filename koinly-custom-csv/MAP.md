# File map

What each file in `koinly-custom-csv/` is for. Start with [README.md](README.md).

## Tree

```text
koinly-custom-csv/
├── README.md                      what the project does, quick start
├── CONTRIBUTING.md                how to report a changed export, add an adapter, write tests
├── CHANGELOG.md                   versions
├── MAP.md                         this file
├── tools/
│   ├── koinlycsv.py               entry point: fetch, build, validate
│   ├── config.example.toml        config template; copy it to private/config.toml
│   ├── make_example.py            regenerates examples/safetrade-quantus/ (fixed seed)
│   ├── koinly_csv/                shared core
│   │   ├── build.py               pipeline: load → check → predict transfers → write → read back
│   │   ├── config.py              reads the TOML config, resolves paths, validates it
│   │   ├── model.py               Money, Row, Issue; amount parsing and formatting
│   │   ├── checks.py              currencies, tags, repeated hashes, running and expected balances
│   │   ├── transfers.py           Koinly's six matching rules, pairs and near misses
│   │   ├── universal.py           reads and writes the Universal template, header checks
│   │   ├── timezones.py           zones, dates that do not exist or happen twice
│   │   ├── currencies.py          plain symbol, SYMBOL:CONTRACT[:CHAIN], ID:<number>
│   │   └── tags.py                Koinly's tags per row type
│   ├── adapters/
│   │   ├── safetrade.py           SafeTrade trades and transactions exports → rows
│   │   ├── quantus.py             Quantus indexer → snapshot (fetch) → rows (build)
│   │   └── evm.py                 EVM receipts → snapshot (fetch) → on-chain side of transfers
│   └── tests/                     unittest suite, invented data only
├── docs/
│   ├── koinly-csv-rules.md        Koinly's rules with a source for each (checked 2026-09-29)
│   ├── after-import-checklist.md  what to check in Koinly after the import
│   ├── writing-an-adapter.md      how to add an exchange or a chain
│   ├── exchanges/safetrade.md     SafeTrade export format and quirks
│   └── chains/quantus.md          Quantus in Koinly, the indexer, the balance check
├── examples/safetrade-quantus/    a complete invented example
│   ├── README.md                  the story behind the example
│   ├── config.toml                the example config
│   ├── input/                     exports, typed-in rows and snapshots
│   └── expected/                  build output; expected/utc/ is the UTC copy
├── skills/koinly-csv/SKILL.md     Claude Code skill: workflow and diagnosis
└── templates/koinly/              Koinly's own templates and SOURCES.md (not MIT)
```

## Data flow

```text
fetch (network, read-only)             build (offline, repeatable)
──────────────────────────             ─────────────────────────────────────────────
Quantus indexer ─► quantus snapshot ─┐
                                     ├─► adapters ─► rows per wallet ─► checks
SafeTrade exports ───────────────────┤                   │
manual files (own zone) ─────────────┘                   ▼
EVM RPC ─► evm snapshot ─────────────────────► on-chain legs ─► transfer prediction
                                                         │
                                  errors? stop, write nothing
                                                         ▼
                              write local zone + utc/ copy ─► read back and compare
```

`validate` runs the same checks and transfer prediction on Universal files made elsewhere.

## Where to change what

| Change | Files |
|---|---|
| a new exchange or chain | `tools/adapters/<name>.py`, `ADAPTERS` in `koinly_csv/config.py`, `_adapter()` in `koinly_csv/build.py`, tests, `docs/exchanges/` or `docs/chains/` |
| a Koinly rule changed | `docs/koinly-csv-rules.md` and the module that enforces it: `tags.py`, `currencies.py`, `transfers.py` or `universal.py` |
| the example story | `tools/make_example.py`, then run it to regenerate `examples/` |
| your own wallets | `private/config.toml` (never tracked) |

## Tracked, generated and ignored

| Path | Status |
|---|---|
| `examples/*/input/`, `examples/*/expected/` | generated by `tools/make_example.py`, tracked; `tools/tests/test_example.py` checks they match |
| `private/` | ignored by git: your config, exports, snapshots and output |
| `output/` (anywhere) | ignored by git: where `build` writes by default |
| `*.csv`, `*.tsv`, `*.json`, spreadsheets, `config.toml` | ignored by git, except Koinly's templates and the example folder named in the root `.gitignore`; a real export cannot be committed by accident. A new example folder must be added to `.gitignore` on purpose |
| `.env*`, keys, archives | ignored by git |
