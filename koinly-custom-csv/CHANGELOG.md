# Changelog

## 0.1.0 (unreleased)

First version.

- `tools/koinlycsv.py` with three commands: `fetch`, `build`, `validate`.
- Universal writer and reader, with a UTC copy of every file and a read-back check.
- Checks: exact columns, currency notation, tags per row type, repeated hashes, running
  balances, expected balances, dates that do not exist or happen twice around daylight saving.
- Prediction of Koinly's transfer matching, with the failed rule for every near miss.
- Adapters: SafeTrade exports, Quantus (QTC) from the public indexer, ERC-20 check on any EVM
  chain (example: Arbitrum One).
- Manual files: rows typed in by hand, in their own time zone, merged without duplicates.
- Invented example `examples/safetrade-quantus/`, regenerated by `tools/make_example.py`.
- Documentation of Koinly's CSV rules with sources, checked on 2026-09-29.
- Claude Code skill `skills/koinly-csv/`.
